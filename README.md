# Charitha Bimsara Adikari — Portfolio

Personal software engineering portfolio built with React, Vite and custom CSS.

Live: https://charithaadikari.vercel.app

## About

A clean, responsive engineering portfolio with:

- Six flagship engineering project showcases
- Nineteen additional archived projects, searchable and filterable
- Accessible project detail pages, preserving existing /projects/:id URLs
- Experience, technical capabilities, education, writing, research and contact sections
- Medium technical articles for Nexa Color Match and MeetMind AI
- Responsive navigation, keyboard focus states, reduced-motion support and SEO metadata
- No fabricated benchmarks or unpublished internal client code

## Local setup

Node.js 22+ recommended.

    npm ci
    npm run dev
    npm run lint
    npm run build

## Content

- src/data/flagships.js — six case studies
- src/data/projects.js — additional public projects
- src/data/experience.js — work experience
- public/showcase/ — project illustrations

Nexa Color Match is collaborative academic research. Team members and IEEE publication details remain on its case-study page. Private client source and data are excluded.

## Deployment

Vercel deploys this React/Vite project from GitHub. Existing portfolio domain and project deep links are retained.
